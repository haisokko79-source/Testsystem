# 🚀 โปรเจกต์ Testsystem ของฉัน

ยินดีต้อนรับสู่คลังเก็บโค้ดแห่งแรกของ **haisokko79**! โปรเจกต์นี้สร้างขึ้นเพื่อฝึกฝนการใช้งาน Git และ GitHub

---

## 📌 สิ่งที่ฉันได้เรียนรู้ในโปรเจกต์นี้
- การตั้งค่า Git พื้นฐานในคอมพิวเตอร์
- การใช้คำสั่ง `git add`, `git commit`, และ `git push`
- การเชื่อมต่อและส่งไฟล์ขึ้น GitHub ผ่าน **VS Code**

## 🛠️ เครื่องมือที่ใช้
1. **Git** สำหรับบันทึกประวัติโค้ด
2. **GitHub** สำหรับเก็บโค้ดออนไลน์
3. **VS Code** สำหรับเขียนและแก้ไขไฟล์

## 📌 สิ่งที่ได้เรียนรู้และลงมือทำแล้ว
- ตั้งค่าระบบ Git พื้นฐานในเครื่องคอมพิวเตอร์ (`git config`)
- สร้างตู้เซฟและบันทึกประวัติไฟล์ (`git init`, `git add`, `git commit`)
- เชื่อมต่อและส่งงานขึ้น GitHub ผ่าน **VS Code** (`git push`)
- เขียนหน้าปกโปรเจกต์ด้วยไฟล์ **Markdown (`.md`)**

## 🧰 เครื่องมือที่ใช้
| เครื่องมือ | หน้าที่การใช้งาน |
|---|---|
| **Git** | ระบบบันทึกประวัติและย้อนเวลาไฟล์ |
| **GitHub** | พื้นที่เก็บโปรเจกต์ออนไลน์บน Cloud |
| **VS Code** | โปรแกรมเขียนโค้ดและจัดการส่งไฟล์ |
